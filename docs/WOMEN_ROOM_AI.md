# 🌷 女性だけの部屋：AIで確認して入る入口（設計案）

2026-11-09 に作りました（`supabase/women_room_ai.sql`・Edge Function `kimetomo-wroom-ai`・`js/women-room-ai.js`）。

決めたこと：
- AIの入口の条件：♀で、一度も♂にしたことがない人。登録から1日以上・投稿かコメント1回以上（2026-11-09 追加、`supabase/women_room_probation.sql`）
- 入ってから7日間は見習い期間：部屋のチャットの写真を送れない・見られない（どの入口でも同じ。管理者と、追加前からいたメンバーは対象外）
- AIで入った人も🌷の印を出せる（部屋のメンバーなので自動で同じ扱い）
- 試せるのは1日1回・合計3回（AIが判定できなかった回は数えない）
- AIは安い Claude Haiku 5.5（ユーザーの希望）
- お題は「片手で指をN本＋もう片方の手でしぐさ」の組み合わせ（左右は問わない）

## ねらい
- 今の入口（管理者に申請・招待リンク）に加えて、**AIが確認して、その場で入れる入口**を増やす。
- 管理者は写真を見ない。写真はどこにも保存しない。
- 今の入口は残す。AIに落とされた人も、今まで通り管理者に申請できる。

## 流れ（使う人から見て）
1. 女性だけの部屋のカードに「📷 AIで確認して入る（管理者は写真を見ません）」ボタンが出る。
   - **男性は申請できない。** プロフィールの性別が♀の人にだけボタンを出す（♂・未設定の人には出さない）。
   - 画面だけでなく、データベースと Edge Function でも「♀でなければ断る」。画面をいじっても通れない。
   - **一度でも♂にしたことがある人も、AIの入口は使えない**（♂→♀に変えて試すのを防ぐ）。性別を♂にしたら「♂にしたことがある」印をデータベースが自動で付け、本人は消せない。
   - 今の「管理者に申請」も、もともと♀の人しか申請できない（データベースで止めている）。
2. 説明を読んで「同意して始める」を押す（説明文は下にあります）。
3. 画面に**お題**が出る。例：「右手でピース✌️して、顔を少し左に向けてください」
   - お題は毎回ちがう。5分で使えなくなる。前から用意した写真を使えなくするため。
4. その場でカメラが開く。**写真を選ぶボタンは作らない**（撮るだけ）。
5. 撮った写真を送ると、数秒で結果が出る。
   - 合格 → そのまま部屋に入る。
   - 不合格 → 「今回は確認できませんでした。管理者に申請することもできます」と案内する。
   - 落ちた理由のくわしい中身は出さない（ずるいやり方の練習に使われないように）。

## 裏の仕組み

### 画面（新しいファイル `js/women-room-ai.js`）
- お題をもらう → カメラで撮る → 小さく縮める（長い辺 768px 程度）→ 送る。
- 写真はスマホの中にも残さない（送ったらすぐ捨てる）。

### Edge Function（新しく `kimetomo-wroom-ai`）
1. ログインしている本人か確認。
2. お題が本人のもの・未使用・5分以内か確認。
3. 回数の確認：**1日1回、合計3回まで**（費用と、くり返し試されるのを防ぐため）。
4. 写真とお題をAI（Claude）に送って、次の4つを答えてもらう。
   - お題のポーズと合っているか
   - その場で撮った実物の写真に見えるか（画面を撮った写真・AIで作った絵・印刷物でないか）
   - 写っている人が女性に見えるか
   - どのくらい自信があるか
5. 4つとも条件を満たしたら合格。データベースの関数で部屋に入れる。
6. **写真・AIの返事の文章は保存しない。ログにも出さない。** 残すのは「合格／不合格・日時・回数」だけ。

### データベース（新しい SQL `supabase/women_room_ai.sql`）
- お題の表（だれに・どのお題・いつまで有効・使ったか）
- 試した記録の表（だれが・いつ・合格か）。写真は入れない。
- プロフィールに「♂にしたことがある」印（`ever_male`）。性別を♂にしたとき、トリガーで自動で付ける。本人は書きかえられない。
  - これが付いている人には、AIの入口のお題を出さない（Edge Function も断る）。
  - 注意：今までの性別の変更の記録は残っていないので、印が付くのは**作った日より後に♂にした人**から。
- 部屋のメンバーに「どの入口で入ったか」（管理者の許可／招待／AI）を記録する。
  - 管理者には「AIで参加」とだけ表示する。写真は見えない。
- 今の守り（♀でない人は入れない・♀をやめたら自動で外れる・通報・管理者が外せる）はそのまま使う。

## 正直に言っておくこと（限界）
- AIが作った写真を、AIが見分けるのはまだ苦手。お題の動きを毎回変えると突破しにくくなるが、0 にはならない。
  - スマホの「顔をリアルタイムで女性に変えるアプリ」を使われると、見抜けないことがある。
- 本物の女性が落とされることもある（短い髪・メイクなし・暗い写真など）。だから管理者への申請は必ず残す。
- 入ったあとの「通報」「管理者が外す」が、いちばん最後の守りになる。

## AIの会社のルール（Anthropic）
- 利用規約は「顔などの生体情報で人を分類し、人種・政治の考え・宗教・性的指向などを推測する」使い方を禁止している。**性別は禁止の一覧には入っていない。**
- ただし「顔で人を分類する仕組み」に近い使い方なので、グレーです。AIが判定を断ることもある。
- 作る前に、Anthropic のルールをもう一度確認する。だめなら、本人確認の専門サービスを使う方法に切りかえる。
- 法律（個人情報保護法）：顔写真は個人情報。海外の会社に送ることを説明して、同意をもらう（上の説明文の同意チェックがそれ）。
