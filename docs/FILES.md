# ファイルごとの仕組みと経緯（キメ友）

CLAUDE.md から移した詳しい説明。そのファイルを直すときに、該当する行だけ検索して読む。

## js/

- `app.js`：本体（ログイン・プロフィール・タイムライン・コメント・リアクション・通知ベル・2段階認証・画像・チャット）。大きいので検索して必要な部分だけ読む。
- `tabs` タブ切替／`maintenance` メンテ表示／`monitoring` エラー報告・解析／`invite` 友達招待／`poll` アンケート／`topic` お題／`mood` 気分／`inapp-browser` アプリ内ブラウザ案内／`update-notice` 更新のお知らせ／`pull-refresh` 引っぱって更新／`linkify` リンク化／`compose-toggle` 投稿欄の開閉・プロフィール編集／`quick-compose` いつでも投稿欄／`chat-latest` チャットの最新へ／`ng-words` 使えない言葉／`soft-filter` 注意する言葉／`pinned-notice` 固定のお知らせ／`bug-report` 不具合報告／`gender-age` 性別・年齢／`support` 応援／`live` リアルタイム更新（新しい投稿の案内・ベル。2026-11-27 から、下のタブの赤い数字〔タイムライン・グループ・管理の「気になる投稿」〕の「どこまで見たか」を同じアカウントの端末どうしでそろえる役目も持つ：見た端末が `kmSeenPush` で `kimetomo_seen_marks`〔1 人 1 行。`supabase/seen_marks.sql`〕に覚え、ほかの端末は同じ接続で知らせを受けて端末の印を進め、`km-seen-sync` で `poll`・`topic`・`admin-tabs` に数え直してもらう。ベルの既読はもともとデータベースにあるので別。パソコンの広い画面では通知がいつも見えているので、手を動かしたら 3 秒後に既読にする〔`app.js`〕）／`admin-ban` `admin-today` `admin-invite` `admin-tabs` 管理者メニュー。
- `chat-reply`：グループチャットの返信（「☺︎＋」のすぐ右の「↩️ 返信」ボタン〔2026-11-27 に選択肢の中から外に出した〕、返信された人にベル・プッシュ `chat_reply`。`supabase/chat_reply.sql`）。
- `comment-reactions`：投稿のコメント・返信へのリアクション（投稿と同じ6種類。「返信する」の行の右に ❤️ と 😊＋。`kimetomo_comment_reactions`、付けられた人にベル・プッシュ〔種類は reaction、ref_id は `rcom:コメントID`〕。`supabase/comment_reactions.sql`）。
- `trade-guard`：売り買いを思わせる書き込みを送る前に止める（2026-11-26。投稿・コメント・グループチャット・個人チャット。確認なしで止める。データベースでも `supabase/trade_guard.sql` のトリガーで止める〔プロフィールの自己紹介も〕。言葉の一覧は正規表現で、JS と SQL の `kimetomo_trade_patterns` を同じにそろえる）。
- `women-guide`：♀と性別を選んでいない人に、プロフィールに固定で出す「女性に便利な機能紹介」（DM対策・性別を隠す・ブロックなど。女性だけの部屋に入れる人・参加中の人には、いちばん上に「部屋に入る・開く」ボタン）。
- `device-cache`：端末に覚えておく（Supabase の負担を減らすため）。
  - 名前・アイコン3時間、管理人の印1時間、メンバー一覧10分、DMの最新。
  - 自分の設定：ブロック・ミュート・メール・プッシュ30分、プロフィール・安心の設定10分。自分で変えたら `kmDC.mine.forget` で消す。
  - グループチャットの各ルームのメッセージ（10分以内に全部読んだものを土台に新しい分だけ読む）、DMの会話（新しい分だけ。1日1回全部読み直す）、入っているルーム一覧10分。
  - アプリの設定〔固定のお知らせ・応援〕10分（`kmDC.setting`、管理者が保存したら `kmDC.del('set-キー')`）。
  - パソコン版も同じコード。キーは `km-c-`、ログアウトで全部消す。
- `lite`：軽量モード（遅い端末だけ、ぼかし・動く背景の光・タブ切替の動き・きらめきを止める）。
  - メモリ4GB以下・4コア以下はすぐ〔iPhone・iPad はどの機種も少なめのコア数を名乗るので、コア数は見ない。2026-11-26〕、ほかは開いて約3秒なめらかさを測って3日覚える。
  - メンバーが切り替える項目はなく自動だけ。キーは `km-lite` でログアウトしても消さない。`<head>` で読み込む。見た目は `glow.css` の最後。
- `dm-extras`：個人チャット（dm.html）のスタンプ（😊から送る・文字が一覧と同じなら大きく表示）・リアクション（相手のメッセージに1つ。`kimetomo_dm_reactions`、外すときは emoji を null）・📌ピン留め（端末だけ、キー `km-dm-pins-自分のID`）。見た目は `css/dm-extras.css`。
- `dm-safety`：個人チャットで受け取ったメッセージを TypeSafe で見分け、受け取った人にだけ注意を出す（お金の話・傷つける言葉・しつこい誘いなど。管理者には知らせず記録もしない。端末にキー `km-dm-safe-会話ID`）。
  - TypeSafe は投稿・コメント・グループチャットの「気になる投稿」（🤖 の印）と不具合の報告の仕分けにも使う：Edge Function `kimetomo-typesafe`（質問の文章としきい値はこのファイルにまとめてある）・`supabase/typesafe_ai.sql`、鍵は Secrets の `TYPESAFE_API_KEY`（ないあいだは何もしない）。
- `tap`：タップの手ごたえ・リアクションのはずみ（2026-11-26）。リアクションを付けた瞬間に `window.kmPop(要素)` で絵文字をぽんっと弾ませ、まわりにきらめきを飛ばす。画面をタップした場所にも、まん中の光・2重の光の輪・きらめき ✦ を11個出す〔2026-11-26 と 11-27 に「もうちょっと派手に」で一段ずつ強くした。前の強さは `css/tap.css` の 5 に書いてある。スクロール・長押し・文字を打つ欄・下のタブでは出さない〕。投稿・コメント・グループチャット・個人チャットから呼ぶ。見た目は `css/tap.css`。
- `insta`・`page-fx`：下の css の同じ名前の行を見る。

## sw.js（いちばん上の階層）

プッシュ通知と、写真（プロフィール写真・投稿の画像）を端末にしまって使い回す（リンクの鍵が変わっても場所で覚える。30日・400枚まで。女性だけの部屋の写真は対象外）。Supabase の通信量を減らすため。

## css/（この順で読み込む。順番を変えない）

- `base` 基本・タイムライン／`nav-profile` 下のタブ・ベル・プロフィール／`features` アンケート・お題・気分など／`login-misc` ログイン・パスワード・リアクション・リンク／`admin` 管理者／`tweaks` 後からの調整／`chat` チャット。
- `desktop`：パソコン用（幅 900px 以上で左メニュー・大きい投稿欄、1200px 以上で通知を右に出す）。
- `motion`：画面の切り替えアニメ・夜のローズ（ピンク→ラベンダー）の飾り・きらめき。
- `glow`：2026-11 の新デザイン（ただよう背景の光・すりガラスの浮いた下タブ・下から出るプロフィール・パソコンの光る左メニュー）。index.html と dm.html の両方。
- `insta`：2026-11-09 の Instagram 風デザイン（glow の後）。平らな背景・枠なしで線の区切り・上に細いロゴの帯とベル・下はアイコンだけのタブ・気分はストーリーズ風の丸。index.html と dm.html の両方。動きは `js/insta.js`：タブとベルの線のアイコン、投稿の編集・削除・引用・通報を「⋯」にまとめる。元に戻すときは2ファイルの読み込み行を消す。
- `tap`：2026-11-26 のタップの手ごたえ（insta の後）。
  - ボタンは押すと少し暗く、リンク・アイコン・名前は押すと薄くなり、離すとふわっと戻る。リアクションのはずみ。
  - 出てくるものの動きもここ：通知・スタンプ選び・絵文字の板・コメント欄はふわっと出る。投稿の「⋯」メニューはスマホ（幅 899px 以下）では下からせり上がるシート＋うしろを暗く〔うしろを押すと閉じる。シートが開いている間だけ `main` の動きの名残を外して、下のタブより手前に出している〕、パソコンではボタンの下にすっと出る。
  - 「視差効果を減らす」でははずませない・動かさない。軽量モードでは、出てくるものの動きだけ止めて、タップのきらめきとリアクションのはずみ・きらめきは出す〔軽量モードのスマホでも出してほしい、という希望から。数個の文字を動かすだけなので軽い。2026-11-26〕。
  - 下のタブを押したときのきらめきもここ（`js/tabs.js` の `kmSparkle`）：✧✦♡ が10個扇の形に広がり、光の輪が出て、選んだアイコンが少し大きく跳ねる〔2026-11-26「タブももうちょっと派手に」。軽量モードでも出す。画面の切り替えそのものには何も付けない〕。
  - 2026-11-27「エフェクトもうちょっと派手に」で、4つとも一段強くした：画面のタップ・下のタブ・リアクション〔1.7倍に弾む・きらめき8個・光の輪〕・ボタン〔縮み .9・まわりの光を強く・離したときのはずみを大きく〕。前の強さは `css/tap.css` の各番号のコメントに書いてある。
  - index.html と dm.html の両方。元に戻すときは `tap.css` と `js/tap.js` の読み込み行を消す。
- `page-fx`：2026-11-26 のページの切り替え（tap の後、いちばん最後）。
  - ①タブの切り替え〔下のタブ・左メニュー〕はエフェクトなし・いちばん速く、がユーザーの希望。付け直さないこと。ページの中〔タイムライン・グループ・プロフィール・管理〕は `js/tabs.js` が何も付けずに切り替える。DM のタブ〔index.html ⇄ dm.html〕は `js/page-fx.js` が切り替えの動きを飛ばす〔タブのリンクを押したことを sessionStorage の `km-fx-tab` に書き、`pageswap`・`pagereveal` で `skipTransition`。`<head>` で `lite.js` のすぐ後に読み込む〕。
  - 経緯：同じ日に「押した場所から光の輪と丸く広がる」「本のページをめくる」→「目障り」、「0.2 秒の控えめな動き」→ iPhone〔iOS 27・Chrome〕のアプリの中では View Transitions でも、画面を直接動かしても、幕をかぶせて消しても、何も出なかった〔原因は分からないまま〕→ エフェクトなしに決定。
  - ②タブ以外でページが変わる移動〔プロフィールから個人チャットを開く・ブラウザの「戻る」など〕は `page-fx.css` が `motion.css` の「左右にスライド＋ぼかし」を上書き：約 0.2 秒で、前の画面がすっと消え、次の画面が下から 6px 寄って出る。軽量モードと「視差効果を減らす」では動かさない。
  - index.html と dm.html の両方。元に戻すときは `page-fx.css` と `js/page-fx.js` の読み込み行を消す。
  - その端末でエフェクトが出るかは `fx-check.html`〔https://kimetomo.com/fx-check.html。ログイン不要・何も送らない。軽量モード・「視差効果を減らす」・切り替えの仕組みの対応を画面に出す〕で調べられる。
